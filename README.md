# ManhwaZ Mihon Extension

Correctly structured Keiyoushi-compatible ManhwaZ source module.

## Important
This repository contains the extension module. The build uses the current
Keiyoushi `extensions-source` framework (`KeiSource`, libVersion 1.6).

Source website: https://www.manhwaz.cc

The ManhwaZ HTML selectors may need adjustment if the site changes.
Do not use this project to bypass authentication, paywalls, DRM, or
anti-bot protections.
